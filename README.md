# Navilan Santhanakrishnan

**Computer Science student at the University of California, Santa Cruz (UC Santa Cruz).**

I build things at the systems layer — local machine learning inference, developer
tooling, and security research. Most of my work is about understanding how systems
actually behave: how they run, how they break, and how they get made faster or safer.

### What I work on

- **Machine learning systems** — running large MoE models on consumer Apple Silicon, quantization, and decode-throughput research
- **Developer tools** — terminal workbenches, agent tooling, MCP servers, local automation
- **Security & systems programming** — protocol observation, low-level architecture, macOS internals
